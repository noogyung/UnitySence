## 1. Rider 스타일 C# 시맨틱 하이라이팅 오버레이 (옵션 토글)

### 1.1 배경 및 목적
* VS Code에서 Microsoft C# 확장(`ms-dotnettools.csharp`)을 활성화하면 Roslyn 언어 서버의 시맨틱 토큰이 기존 TextMate 문법 색상을 덮어쓰면서(`public` 등 접근 제한자가 일반 `keyword`와 동일 색상으로 통일됨) 가독성이 떨어지는 경우가 많다.
* JetBrains Rider 테마는 Unity C# 코드 가독성이 뛰어나지만, 별도 컬러 테마 확장을 적용하면 **에디터 배경색·사이드바·탭 등 워크벤치 UI 전체 색상까지 강제로 변경**되는 불편함이 있다.
* 이에 **현재 사용자가 사용 중인 테마의 배경과 UI는 그대로 유지하면서**, C# 코드의 시맨틱 토큰 색상만 JetBrains Rider Dark 스타일로 선택 적용하고 언제든 켜고 끌 수 있는 옵션을 제공한다.

---

### 1.2 설정 옵션 및 커맨드 (`packages/extension/package.json`)

| 항목 | 타입 / 기본값 | 설명 |
| :--- | :--- | :--- |
| `unitySense.csharp.riderHighlighting.enabled` | `boolean` (기본값: `false`) | 현재 테마의 배경과 UI는 유지하면서 C# 코드 색상만 JetBrains Rider 스타일 시맨틱 하이라이팅으로 적용합니다. |
| `unitySense.csharp.riderHighlighting.distinguishStructs` | `boolean` (기본값: `true`) | `struct`(`float3`, `NativeArray`, `IJob` 등)를 `class`와 구분되는 색상으로 강조합니다. |
| `unitySense.toggleRiderHighlighting` (Command) | `[UnitySense] Rider 스타일 C# 하이라이팅 켜기/끄기` | 명령 팔레트에서 원클릭으로 켜고 끄는 토글 커맨드. |

  3. **즉시 반영**: 설정 변경(`onDidChangeConfiguration`) 또는 토글 커맨드 실행 시 VS Code 재시작 없이 에디터 색상이 즉시 갱신된다.

## 2. Rider 스타일 경량 Git Blame (Read-Only Annotate)

> **참조 대화**: [Unity Shader Keyword CBUFFER Warning And Git Blame](conversation://75d4a795-1e70-4f6b-bf59-aaaea99564bc)

### 2.1 배경 및 목적
* GitFork 등 전용 Git 클라이언트를 별도로 사용하는 워크플로에서는 VS Code 내 거대한 Git 관리 UI(커밋/푸시/브랜치/유료 기능)가 불필요하고 무겁다.
* 기본 Git Blame 확장들은 마우스 오버를 해야만 정보가 보이는 경우가 많아, **JetBrains Rider의 "Annotate with Git Blame"** 처럼 마우스 오버 없이도 코드 왼쪽에 작성자·날짜가 열(column) 형태로 상시 표시되는 가벼운 **읽기 전용(Read-Only) Git Blame** 기능을 UnitySense에 내장한다.

---

### 2.2 설정 옵션 및 커맨드 (`packages/extension/package.json`)

| 항목 | 타입 / 기본값 | 설명 |
| :--- | :--- | :--- |
| `unitySense.gitBlame.enabled` | `boolean` (기본값: `true`) | Rider 스타일 경량 Git Blame 기능(토글 커맨드 및 메뉴)을 활성화합니다. |
| `unitySense.gitBlame.inlineCurrentLine` | `boolean` (기본값: `false`) | 평소 작업 시 현재 커서가 위치한 줄 끝에 작성자·날짜·커밋 요약을 얇게 상시 표시합니다 (하이브리드 모드 옵션). |
| `unitySense.gitBlame.dateFormat` | `string` (`"YYYY-MM-DD"` \| `"relative"`, 기본값: `"YYYY-MM-DD"`) | Blame 열에 표시할 날짜 형식. |
| `unitySense.gitBlame.showHeatStrip` | `boolean` (기본값: `true`) | Blame 열 우측 경계선 색상을 커밋 최신도에 따라 단계별로 구분 표시합니다. |
| `unitySense.toggleGitBlame` (Command) | `[UnitySense] Git Blame 주석 켜기/끄기 (Annotate)` | 에디터 우클릭 메뉴(`editor/context`, `editor/lineNumber/context`) 및 단축키로 현재 파일의 좌측 고정 Blame 열을 토글합니다. |
| `unitySense.copyBlameCommitHash` (Command) | `[UnitySense] Blame 커밋 해시 복사` | 호버 팝업 내 버튼에서 호출되어 커밋 해시를 클립보드에 복사합니다 (GitFork에서 바로 검색용). |

---

### 2.3 UI 및 핵심 기능 설계

#### A. 좌측 고정 Blame 열 (Rider Annotate 토글)
VS Code API 제약상 줄 번호 왼쪽 거터에는 텍스트를 삽입할 수 없으므로, 줄 번호 바로 오른쪽 코드 시작 위치에 `TextEditorDecorationType`의 `before` 옵션으로 고정 폭 열을 렌더링한다.

```text
 12 │ 2026-10-14  홍길동   │ CBUFFER_START(UnityPerMaterial)
 13 │                      │     float4 _BaseColor;
 14 │                      │     float _Cutoff;
 15 │ 2026-11-02  김철수   │     float _Metallic;
 16 │ 2026-11-20  이영희   │     float _Smoothness;
 17 │ 2026-10-14  홍길동   │ CBUFFER_END
```

* **연속 커밋 그룹핑**: 같은 커밋 해시가 연속된 줄(예: 12~14번 줄)에서는 첫 줄에만 날짜·작성자를 표시하고 나머지 줄은 공백 패딩으로 정렬해 시각적 노이즈를 최소화한다.
* **최신성 컬러 바(Heat Strip)**: 열 우측 경계선(`border-right`) 색상을 커밋 경과일 기준으로 단계화해 최근 수정된 블록을 한눈에 파악한다.
* **호버 상세 팝업 & GitFork 친화 연동**: Blame 영역에 마우스를 올리면 전체 커밋 해시, 작성자, 정확한 일시, 커밋 메시지를 마크다운 팝업으로 표시하며, **`커밋 해시 복사`** 링크(`command:unitySense.copyBlameCommitHash?...`)를 제공한다.
* **미커밋 라인 처리**: 아직 커밋되지 않은 수정 라인(`00000000...`)은 `Not Committed Yet`으로 구분 표시한다.

#### B. 현재 줄 상시 인라인 표시 (선택 옵션: `inlineCurrentLine`)
* `unitySense.gitBlame.inlineCurrentLine`이 `true`인 경우, 전체 Blame 열을 켜지 않은 상태에서도 현재 커서 라인 끝에 `after` 데코레이션으로 `김철수, 3주 전 · Add metallic property` 형태의 얇은 요약을 상시 표시한다.

## 3. 직렬화 필드 인스펙터 값 CodeLens 숨김 옵션 (기본 숨김)

### 3.1 배경 및 목적
* 프로퍼티/필드 위에 표시되는 `인스펙터 값: ...` CodeLens는 필드가 많은 스크립트에서 화면을 과도하게 차지할 수 있다.
* 이를 별도 옵션으로 분리하고 **기본값을 숨김(`false`)** 으로 설정하여 기본 코드 가독성을 높이고, 필요할 때만 켜서 확인할 수 있게 한다.

### 3.2 설정 및 구현 설계
* **설정 추가 (`packages/extension/package.json`)**:
  * `unitySense.codeLens.showSerializedFieldValues` (`boolean`, 기본값: `false`)
  * 설명: `"[UnitySense] 직렬화된 필드/프로퍼티 위에 씬·프리팹 인스펙터 값 미리보기 CodeLens를 표시합니다."`
* **수정 대상**:
  * `packages/extension/src/codelens/unityAssetUsageCodeLensProvider.ts`
    * 옵션이 `false`일 때는 필드 단위 인스펙터 값 CodeLens 생성을 건너뛰고, 불필요한 `daemonClient.getSerializedValues(scriptGuid)` RPC 호출도 생략해 성능을 최적화한다.
    * `onDidChangeConfiguration`에서 해당 옵션 변경 시 `refresh()`를 호출해 즉시 반영한다.
  * `packages/extension/test/codelens/unityAssetUsageCodeLensProvider.test.ts`
    * 기본값(`false`)일 때 인스펙터 값 CodeLens가 미표시되고 `getSerializedValues`가 호출되지 않음을 검증.
    * `true`로 설정했을 때 기존과 동일하게 인스펙터 값 CodeLens가 표시됨을 검증.

## 5. Antigravity IDE 지원 및 Open VSX 배포 파이프라인 연동

### 5.1 배경 및 목적
* Antigravity IDE는 VS Code 기반이지만 기본 확장 마켓플레이스로 **Open VSX Registry (`open-vsx.org`)** 를 사용한다.
* Antigravity IDE 사용자가 확장 검색창에서 `UnitySense`를 바로 검색·설치·자동 업데이트할 수 있고, Antigravity IDE 환경(Open VSX C# 확장 포함)에서도 모든 기능이 오류 없이 동작하도록 호환성과 배포 파이프라인을 정비한다.

### 5.2 구현 및 배포 설계
1. **Open VSX Registry 자동 게시 파이프라인 추가**
   * 수정 대상: `.github/workflows/release-vsix.yml`, `docs/PUBLISHING.md`
   * 태그 릴리스(`v*`) 및 수동 워크플로 실행 시 `OVSX_PAT` 시크릿이 설정되어 있으면 `npx --yes ovsx publish <vsix>`를 통해 Open VSX에도 동시 게시 (`VSCE_PAT` + `OVSX_PAT` 듀얼 마켓 배포).
   * `docs/PUBLISHING.md`에 Open VSX 네임스페이스(`noogkim`) 클레임 및 `OVSX_PAT` 발급·등록 절차 추가.
2. **Antigravity IDE 런타임 호환성 검증 및 보강**
   * `packages/extension/package.json`의 `engines.vscode`(`^1.90.0`) 및 `contributes` 스키마가 Antigravity IDE에서 경고 없이 로드되는지 점검.
   * C# 확장 의존 경로(`packages/extension/src/analyzers/csharpLightweightDiagnostics.ts`, `extension.ts` 등)에서 Microsoft 전용 확장 ID(`ms-dotnettools.csharp`) 하드코딩이나 미설치 시 예외 발생 지점이 없는지 전수 점검하고, Open VSX C# 확장(`muhammad-sammy.csharp` 등) 또는 C# LSP 미활성 상태에서도 안전하게 폴백(graceful fallback)하도록 보강.
   * Rider 스타일 시맨틱 하이라이팅 오버레이(`Section 1`) 및 Git Blame(`Section 2`)이 Antigravity IDE의 사용자 설정 및 에디터 데코레이션에서 동일하게 동작하는지 검증.

### 5.3 검증 기준 (Definition of Done)
1. `.github/workflows/release-vsix.yml`에서 `OVSX_PAT` 유무에 따라 안전하게 Open VSX 게시가 수행(또는 미설정 시 스킵)된다.
2. 생성된 `dist/unitysense-1.1.0.vsix`를 Antigravity IDE에 설치했을 때 활성화 에러 없이 ShaderLab/HLSL, C# 진단, CodeLens, Git Blame, Rider 하이라이팅 토글이 정상 동작한다.
3. Open VSX(`open-vsx.org`) 게시 후 Antigravity IDE 확장 마켓플레이스 검색으로 직접 설치 가능하다.
