## 1. Rider 스타일 C# 시맨틱 하이라이팅 통일 (Bug 1)

### 원인 분석
* `unitySense.csharp.riderHighlighting.distinguishStructs`의 기본값이 `true`로 설정되어 있어, 실제 JetBrains Rider Dark 테마에서 연보라(`#C191FF`)로 통일되는 구조체 타입(`float3`, `NativeArray`, `FixedString64Bytes`, `CustomBlittableStruct`)이 연두색(`#86C691`)으로 표시되어 Rider 스타일과 불일치했다.
* Roslyn C# 언어 서버가 발행하는 추가 시맨틱 토큰(`recordClass`, `recordStruct`, `delegate`, `event`, `constant`, `preprocessorKeyword`, `operator`, `punctuation`, `stringVerbatim`, `xmlDocCommentText`)이 누락되어 일부 토큰이 기존 테마 색으로 남아 혼재되었다.

### 수정 내용
* `unitySense.csharp.riderHighlighting.distinguishStructs` 기본값을 **`false`** 로 변경하여 기본 활성화 시 실제 JetBrains Rider Dark 팔레트와 100% 일치시킨다.
* `RIDER_CSHARP_BASE_RULES`에 모든 주요 C# Roslyn 시맨틱 토큰을 Rider Dark 표준 색상으로 보강한다:
  * `keyword:csharp`, `controlKeyword:csharp`, `preprocessorKeyword:csharp`: `#6C95EB`
  * `class:csharp`, `struct:csharp`, `recordClass:csharp`, `recordStruct:csharp`, `interface:csharp`, `enum:csharp`, `delegate:csharp`, `typeParameter:csharp`: `#C191FF` (`distinguishStructs: true` 선택 시에만 `struct:csharp`/`recordStruct:csharp`를 `#86C691`로 분리)
  * `method:csharp`, `extensionMethod:csharp`: `#39CC8F`
  * `field:csharp`, `property:csharp`, `enumMember:csharp`, `event:csharp`, `constant:csharp`: `#66C3CC`
  * `parameter:csharp`, `variable:csharp`, `namespace:csharp`: `#D0D0D0`
  * `string:csharp`, `stringVerbatim:csharp`: `#C9A26D`
  * `number:csharp`: `#ED94C0`
  * `comment:csharp`, `xmlDocCommentText:csharp`: `#85C46C`
  * `operator:csharp`, `punctuation:csharp`: `#BDBDBD`

## 2. Rider 스타일 Git Blame 좌측 고정 폭 열 & 히트맵 렌더링 수정 (Bug 2)

### 원인 분석
1. **옵션 연동 누락**: 설정에서 `unitySense.gitBlame.*` 옵션을 모두 켜도 좌측 Blame 열을 전역 활성화하는 설정이 없어, 개별 파일마다 `unitySense.toggleGitBlame` 커맨드를 실행하지 않으면 현재 줄 인라인 텍스트만 표시되었다.
2. **잘못된 CSS 단축 문법**: `before` 데코레이션에 `border: '0 2px 0 0 solid <color>'`가 전달되어 브라우저/VS Code CSS 파서에서 무시되었고, Rider Blame의 핵심인 **커밋 최신도별 배경 음영(Heat Map Background)** 이 빠져 있었다.
3. **연속 커밋 생략 기본값**: 연속 커밋의 2번째 줄부터 텍스트를 비워 두어 Rider 기본 UI(모든 줄에 날짜·작성자 + 최신도 배경 음영 표시)와 시각적으로 달랐다.

### 수정 내용
* 설정 2종 추가 (`packages/extension/package.json`):
  * `unitySense.gitBlame.showGutterColumn` (`boolean`, 기본값 `false`): 활성화 시 모든 열린 파일에 좌측 고정 폭 Git Blame 열을 즉시 상시 표시. (`unitySense.toggleGitBlame` 커맨드는 현재 파일에 대한 개별 On/Off 오버라이드로 연동)
  * `unitySense.gitBlame.groupConsecutiveCommits` (`boolean`, 기본값 `false`): 기본값 `false`로 Rider처럼 모든 줄에 `날짜  작성자`를 표시하고, `true`로 켜면 연속 커밋의 첫 줄만 표시.
* 유효한 CSS 기반 Rider 스타일 렌더링 (`gitBlameParser.ts`, `riderGitBlameProvider.ts`):
  * `computeHeatBackgroundColor(authorTimeSec, isUncommitted, nowMs)` 추가 — 커밋 최신도에 따라 Rider 스타일의 파란색 계열 배경 음영(`rgba(56, 139, 253, 0.34)` → `0.22` → `0.13` → `rgba(148, 163, 184, 0.08)` → `0.04`) 적용.
  * 잘못된 `border` 속성 제거 → `backgroundColor` + `textDecoration: 'none; border-right: 2px solid <heatColor>; padding: 0 8px 0 6px;'`로 최신성 컬러 바와 고정 폭 열이 정확히 렌더링되도록 수정.
